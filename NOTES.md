## Множественное число в PR #17

Ядро переводит строку целиком, а русскому нужны три формы (1 день, 2 дня,
5 дней), которых в английском источнике нет. Добавлено в `Locale.lua`:
перевод может быть таблицей из трёх строк, форма выбирается по первому числу
в сообщении, `language.forms(n)` в локали возвращает 1, 2 или 3. Строки без
чисел работают как раньше, zhCN не меняется. Ограничение: два числа в одном
сообщении («импортировано %d персонажей и %d цен») не поддержать — такие
строки переписаны без согласования («персонажей — %d, цен — %d»).

Где английский приклеивает к числу только «s» (`%d group%s`), таблица
переводит готовую строку целиком: ключ — отрендеренный текст с числом, и
форма выбирается по нему же (см. `PLURAL` в генераторе). Иначе в русскую
фразу попадала бы английская «s» («2 s»).

В 0.27 часть кода сначала переводит шаблон, а потом подставляет числа
(`LocalizeText(...):format(...)`); для русского это теряет форму. В PR для
таких сообщений есть `ns.LocalizeFormatted(template, ...)`: локаль с
`language.forms` форматирует строку и переводит её целиком, остальные
переводят шаблон, как раньше (zhCN не меняется). Им заменены сообщения с
числом и склоняемым словом: отмена перебитых лотов, очередь покупок,
слежение, новые сделки, пустой список рецептов. Ключи для них — в
`PLURAL`/`MANUAL`, а не в построчном сопоставлении.

## Как собрать ruRU из `ru`

Ветка `ru` — источник перевода; таблица генерируется, а не пишется руками:

1. переключиться на `locale-ru-026` (там лежит `Locales/ruRU.lua`);
2. `git show ru:tools/build-ru-locale.py > tools/build-ru-locale.py` — скрипт
   хранится в `ru` и в PR не входит; он читает `ru` через `git show`,
   сопоставляет литералы построчно и пишет таблицу; справку сопоставляет по
   разделам (новый раздел сдвигает темы), ручные добавки (числа, склейки вроде
   `"Same as " .. name`, заголовки правил) — в самом скрипте,
   `RU_PREFIX = ""`; после сборки временный файл удалить;
3. `git show ru:tools/list-ru-gaps.py > /tmp/list-ru-gaps.py &&
   python3 /tmp/list-ru-gaps.py` — что осталось без перевода;
4. тесты: `lua5.1 tests/run.lua` из корня (Lua 5.1; на macOS собирается из
   <https://www.lua.org/ftp/lua-5.1.5.tar.gz>, `make macosx`).

В `locale-ru` тесты зелёные: 539 при `TZ=UTC`. В ветке `ru` они падают на
английских ожиданиях (71 из 534) — текст переведён на месте, а проверки ищут
английские строки. `retention` зависит от часового пояса, в MSK+3 не проходит.
