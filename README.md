# Forever Ledger — русская локализация

Перевод аддона **Forever Ledger 0.20.0** для WoW Forever (клиент `ruRU`).
Оригинал: <https://github.com/ivellos/forever-ledger> (MIT).

Здесь лежит не просто копия, а git-репозиторий с двумя ветками, чтобы
обновление аддона не стирало перевод насовсем.

## Ветки

- `upstream` — чистая версия аддона, без перевода. Сюда добавляются новые версии.
- `ru` — перевод. Это то, что устанавливается в игру.

История у веток общая: `ru` ответвилась от `upstream/0.20.0`. Поэтому новая
версия вливается в перевод трёхсторонним слиянием: git сохраняет перевод там,
где оригинальный текст не менялся, и показывает конфликты там, где менялся.

## Как обновить аддон

1. Обновите аддон любым способом (CurseForge, Wago, вручную) — пусть новая
   версия встанет в папку игры как обычно.
2. Скопируйте её в репозиторий и слейте с переводом:

   ```sh
   cd ~/Documents/ForeverLedger-ru
   ./update.sh "/Volumes/SSD_WD_BLUE/World of Warcraft/_forever_/Interface/AddOns/ForeverLedger"
   ```

   Либо укажите папку со скачанной новой версией.

3. Если git сообщит о конфликтах, откройте перечисленные файлы, оставьте
   русский текст и правки новой версии, затем:

   ```sh
   git add -A && git commit
   ```

4. Посмотрите, не появились ли новые английские строки:

   ```sh
   python3 find-english.py
   ```

5. Установите перевод в игру (старая версия архивируется в `~/Downloads`):

   ```sh
   ./install.sh
   ```

6. В игре: `/reload`.

## Что важно знать

- Перевод сделан **прямо в файлах аддона**, а не отдельным аддоном. Поэтому
  обновление, установленное поверх, затирает его — пока вы не выполните
  `update.sh`.
- Новые строки новой версии останутся английскими: их видно через
  `find-english.py`, дальше обычная правка файла и коммит.
- `Locale.lua` и строка в `ForeverLedger.toc` — часть перевода; при слиянии они
  сохраняются.
- Настройки и прогресс в `WTF` не затрагиваются: репозиторий работает только
  с папкой `Interface/AddOns/ForeverLedger`.

## Публикация перевода автору

У аддона есть официальный репозиторий и открытый PR с китайской локализацией
(см. `NOTES.md`). Если автор примет локализацию в таком же виде, перевод можно
будет перенести в upstream и больше не поддерживать вручную.
